# Mohanraj R | Portfolio

Static site: `index.html`, `style.css`, `script.js` and `mohanraj.jpg`. No build step.

## Before you publish
1. Open `script.js` and fill in the `LINKS` block at the top (LinkedIn, GitHub, resume file, project repo). Empty entries stay hidden.
2. To offer a resume download, put the PDF next to `index.html` and set `resume` to its file name.

## Publish for free
- Vercel or Netlify: drag this folder onto the dashboard.
- GitHub Pages: push the folder to a repository, then Settings > Pages.
